# glTF anisotropy and diffuse transmission

The loader reads `KHR_materials_anisotropy` direction from linear texture RG and multiplies the strength by B. The shader rotates the direction in the signed tangent frame and projects it onto the shading plane. `KHR_materials_diffuse_transmission` uses the linear alpha channel of its factor texture and a separate sRGB color texture. Each texture retains its own UV set and transform. Khronos lists diffuse transmission as a Release Candidate. [Anisotropy specification](https://github.com/KhronosGroup/glTF/blob/main/extensions/2.0/Khronos/KHR_materials_anisotropy/README.md), [diffuse transmission specification](https://github.com/KhronosGroup/glTF/blob/main/extensions/2.0/Khronos/KHR_materials_diffuse_transmission/README.md)

Forward opaque, deferred lighting, and the shared transparent pass use the same layered direct-light evaluation. Anisotropy changes the base specular lobe and bends the normal used to sample the prefiltered environment. The direct model uses elliptical GGX with the renderer's existing Schlick masking approximation. Area lights evaluate the new lobes through the sampled path. Diffuse transmission takes energy from base diffuse reflection and uses independent back-side lighting and color. Alpha coverage and specular transmission retain their existing material controls.

Deferred raster allocates two `RGBA16F` attachments when a scene first uses either extension. The auxiliary pass replays opaque surface ownership against the G-buffer depth. Ordinary owners write zero, including at equal depth. Diffuse color is stored premultiplied by its factor so MSAA resolve preserves the color and weight of covered samples. Deferred lighting evaluates the resolved material once per pixel.

Probe tracing samples the same three texture roles at base LOD. At sampled zero strength and transmission, probe-hit shading uses the existing diffuse response. Active lobes use layered direct evaluation and diffuse transmission can also receive feedback from the opposite hemisphere. Probe updates remain bounded, and mixtures with stochastic dielectric continuation are unsupported. The progressive reference path tracer reports active anisotropy and diffuse transmission as unsupported until it can sample those lobes with matching probability densities.

The GPU contracts cover CPU/GPU material layout, signed tangent frames, layered direct lighting, zero-factor compatibility, and actual four-sample resolves. Run them with `CONTAINER_RUN_GPU_EXTENDED_PBR=1` and select `extended_pbr_gpu_tests` and `extended_pbr_resolve_gpu_tests` in CTest. `tests/validation/generate_extended_pbr_reference.py` regenerates the binary64 reference fixture.

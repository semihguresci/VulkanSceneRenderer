# Local ComfyUI generation

The optional **ComfyUI Generation** window submits an environment panorama or
restyles a capture of the current viewport. It uses a separate local Python
adapter. Normal rendering, script captures, and exact-sample reference captures
run independently of the adapter and its models.

## Setup

Start ComfyUI on `127.0.0.1`. Install a compatible checkpoint yourself and
set `ckpt_name` in the starter API workflows to its exact filename. The starter
graphs use the standard ComfyUI checkpoint, text, image and sampling nodes. A
custom graph can use a panorama model or preserve geometry with stronger image
conditioning. Use workflows and models you trust. [ComfyUI setup](https://docs.comfy.org/installation)

Create a private local folder shared by the renderer and adapter. In PowerShell,
run the adapter from the repository using the Python environment from ComfyUI
if PNG panorama conversion is needed. That conversion requires Pillow.

```powershell
$bridge = New-Item -ItemType Directory -Force out/comfyui-jobs
python tools/comfyui_bridge.py --root $bridge.FullName `
  --hdri-workflow tools/comfyui_workflows/hdri.json `
  --restyle-workflow tools/comfyui_workflows/restyle.json
```

In a separate terminal, set the root to the same directory and start the editor.
The window opens when the option is set. F11 toggles it. From an extracted
Windows package, run the same adapter command in the package directory and
launch its `VulkanSceneRenderer.exe` directly.

```powershell
$env:CONTAINER_COMFYUI_ROOT = (Resolve-Path out/comfyui-jobs).Path
& .\out\build\feature-parity\VulkanSceneRenderer.exe
```

The adapter's default ComfyUI port is 8188. Use `--port` for a different local
port. A single adapter watches a bridge directory. Either workflow argument
can be omitted when using only one workflow. It communicates with ComfyUI over
IPv4 loopback. The renderer communicates through local files. [ComfyUI server routes](https://docs.comfy.org/development/comfyui-server/comms_routes)

## Generate and apply

1. Choose **Environment panorama** or **Restyle viewport**. Select a prompt
   preset or write a prompt, set a seed, and start generation.
2. The status shows the capture, queue, generation, and download stages.
   Cancel discards the local result immediately and requests cancellation of
   that ComfyUI job. With older ComfyUI versions, a queued prompt can be removed
   by ID and an already running prompt may finish on the server. Cancelling
   during a viewport upload prevents prompt submission once the upload returns.
   If an acknowledged job disappears from both the queue and history, the
   bridge reports the missing job so you can start a new request.
3. Select **Apply generated environment** when a panorama is ready. The normal
   environment importer validates the 2:1 image, generates IBL, and preserves
   the previous environment if import fails.
4. A restyled PNG appears under **Generated result**. Enter an export path and
   select **Save generated PNG** to make a separate copy. The export requires
   an unused `.png` path. The generated preview is separate from the live scene
   and from viewport-only screenshots. The preview is at most 1024 pixels on
   its longest side. Export keeps the original generated PNG bytes.

## Workflow inputs and outputs

Provide ComfyUI API-format JSON with a node map and `class_type` and `inputs`
for each node. Set complete input values to `${prompt}` and `${seed}` wherever
the prompt and integer seed belong. For restyling, set the `LoadImage` filename
to `${image}`. The adapter uploads the renderer's viewport-only PNG and
substitutes the returned ComfyUI filename. The starter graphs illustrate the
structure and can be edited for the available checkpoint and viewport size.

Use an output node whose history record returns a saved file under `images`
or `files` with `type` set to `output`. Restyling accepts an 8-bit PNG up to
4096 pixels per side. Environment generation accepts 2:1 Radiance HDR and
single-part OpenEXR. It also converts a 2:1 PNG up to 4096 pixels wide to linear
Radiance RGBE. The conversion preserves the PNG's display-color range and
cannot recover lighting intensity beyond it. Panoramas generated by a general
image model may have a visible seam. Use a panorama workflow for seam control.

Each job writes to a unique `jobs/<id>` directory below the configured root.
Inputs and generated assets are limited to 64 MiB per file. The renderer rejects
unexpected output paths, invalid image data, late results, and results from an
older job. Jobs time out after 20 minutes. Keep the job directories for the
generated assets or remove them after the job has finished and the result has
been exported.

Run the loopback protocol regression with
`python -B tests/validation/comfyui_bridge_regression.py`. The native
`comfyui_bridge_tests` exercises the renderer worker, captured input, PNG
decoding, cancellation, and stale responses. The loopback regression covers
queue-to-history transitions, disappeared jobs, and broken HTTP responses.

For scripted testing, add a `comfyUi` capture-sequence event with one of the
actions `generate-environment`, `restyle-viewport`, `apply-environment` or
`cancel`. A generation action takes a prompt and an optional unsigned seed.
With `"wait": true`, the capture loop continues rendering for up to 30 seconds
before taking the scheduled screenshot. The event requires
`CONTAINER_COMFYUI_ROOT`. Ordinary capture sequences omit this event and keep
the bridge inactive even if the environment variable is set. The native mock
regression at `tests/validation/comfyui_runtime_regression.py` runs the actual
adapter against a local HTTP mock. It checks that rendering continues while the
adapter waits for a response.
